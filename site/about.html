About

Name

The project was called Resonance3D and is now Xash3D-FWGS-XBOX. Older changelog entries, the divergence ledger and the // Resonance3D (#NN) markers in the source keep the old name.

Credits

This project is a derivative work. It exists because of:

  • Xash3D-FWGS and its contributors, the engine this port is built on.
  • Uncle Mike, original author of Xash3D, whose copyright headers are throughout the tree.
  • Valve, for Half-Life and the original GoldSrc engine and SDK.
  • XboxDev / nxdk, the open-source homebrew SDK this port is built against, including pbkit, the NV2A pushbuffer library.
  • FWGS/library-suffix, platform detection for the build system.
  • xemu, the Xbox emulator used for development, and xashPS3, a sibling console port whose porting log was a useful map.

Licence

Xash3D-FWGS is licensed GPL-3.0-or-later, and so is this port. This repository contains no Valve assets. Running the game requires your own legally obtained copy of Half-Life; the baker's archives are made locally and are not redistributable.

AI disclosure

Significant portions of this port, including platform bring-up, build-system integration, the renderer, audio and input backends, the asset pipeline and bug fixes across the engine, were developed with the assistance of Claude (Anthropic), used as a coding tool under human direction and review.
