Performance

Frame-time recordings from the Xbox build, as full interactive reports: per-map frame rate, where the CPU time goes, and how each optimisation moved the numbers. The target and the list of changes are on the Progress page.

Real console or emulator. A report says which one it is. Console reports are from a retail Xbox (733 MHz Pentium III). Emulator reports time xemu on a PC: the work counters in them are exact, the times are not the console's.

Adding a report

This page lists whatever is in docs/r3d/reports/ when the site is built, so a new measurement is published without editing the site:

  1. Record on the console with the frame-time recorder and fetch the files: python tools/frametime-report.py fetch --host <console IP> --out recordings/ --label <name>
  2. Build the report: python tools/frametime-report.py report recordings/ --label <name> -o docs/r3d/reports/<name>.html
  3. Commit it, and run the Pages workflow. The report appears here with its title and summary taken from the file.

The step-by-step console report combines many recordings, so it is updated by editing its own file; a report made by frametime-report.py needs nothing beyond the three steps.
